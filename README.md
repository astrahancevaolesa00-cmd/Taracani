Руководство пользователя

Данная игра "Тараканьи бега" является интересной и увлекательной игрой для детей!

Цель игры заключается в том ,чтобы угадать какой из тараканов прибежит первым. Исход игры абсолютно случаен и его невозможно предугадать.

Игровое поле состоит из беговой дорожки для тараканов ,по которой они бегут.

Интерфейс:

1.При запуске игры пользователи должны дать название каждому таракану.

<img width="802" height="447" alt="image" src="https://github.com/user-attachments/assets/f8f00aa6-a84e-401f-8703-5c197963cbfe" />

2. Далее ,чтобы начать игру, нажмите кнопку "Старт" ,которая находится ниже игрового поля.

<img width="801" height="477" alt="image" src="https://github.com/user-attachments/assets/5257b069-12ac-41f9-96ab-e27a87643702" />

3. Когда запустится игра, тараканы побегут с разной скоростью и с рандомным шагом.

<img width="803" height="479" alt="image" src="https://github.com/user-attachments/assets/bffdbd02-b134-418f-95e9-d8bafdd15c07" />

4.После того как один из тараканов добежит до финиша первым ,высветится какой из игроков победил.

<img width="802" height="480" alt="image" src="https://github.com/user-attachments/assets/02c4aa36-3e0e-4819-a7bb-a4f8dc51c165" />

5.Чтобы начать игру заново ,нажмите кнопку "Сброс".

<img width="800" height="482" alt="image" src="https://github.com/user-attachments/assets/a9613251-3339-44c6-96a5-f8d568b557c1" />
